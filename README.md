# Women's Soccer Injury Risk

女足运动员伤病风险建模与跨队伍评价研究代码快照，包含 SoccerMon 源域处理、本地队伍目标域处理、运动员分组验证、模型比较、冻结迁移、校准、预警预算分析和模型归因脚本。

> **研究状态：审查中，不是论文最终复现版本。** 2026-11-19 的方法学审查发现，当前自然日/滚动窗口实现仍有结局定义、时间窗口和跨队伍可比性问题。仓库中的历史结果文件名或脚本注释即使出现“final”“locked”“零泄露”等字样，也不应被理解为独立验证或可直接投稿的证据。请先阅读 [ACADEMIC_REVIEW.md](ACADEMIC_REVIEW.md)。本快照也不得与后续采用记录序列定义的 Emon 管线或结果混用。

## 公开范围

本仓库只公开研究代码和方法说明，不包含以下内容：

- 本地队伍原始或处理后的健康、问卷、伤病、训练、GPS/IMU 数据；
- SoccerMon 原始逐记录数据（需按其原始发布方的数据许可单独获取）；
- 可回溯到单名运动员的预测、轨迹、折分明细或映射表；
- 尚未重新验证的历史结果表和论文图件；
- 虚拟环境、IDE 配置、缓存和模型训练日志。

这些边界由 `.gitignore` 强制执行。请勿使用 `git add -f` 绕过它们。数据可得性和伦理边界见 [DATA_AVAILABILITY.md](DATA_AVAILABILITY.md)。

## 环境

代码在 Python 3.14 环境中完成了语法检查。安装当前环境记录的依赖：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

固定版本反映审查时的本地环境，不代表所有平台均已完成端到端复现。当前公开仓库不附受限数据，因此不能仅靠克隆仓库复算论文结果。

## 目录

- `src/`：历史分析脚本，按 `step01` 至 `step15` 编号；编号体现开发顺序，不等于推荐执行顺序。
- `data/raw/`：仅保留空目录占位符；真实数据不会提交。
- `data/processed/`：仅保留空目录占位符；派生健康数据不会提交。
- `outputs/`：仅保留空目录占位符；未重新审查的输出不会提交。
- `womens_soccer_pycharm_framework_guide.md`：历史流程与论文映射记录，其中数值属于旧管线记录，不是当前正式结论。

## 最低复现要求

若在获授权的私有环境中复现，至少需要先完成：统一源域与目标域结局定义；明确预测时点和观察窗口；按日历时间或明确的记录序列重建标签；把特征筛选、填补、缩放、重采样、调参、校准和阈值选择全部限制在训练折内；冻结源域模型后再进行目标队伍直接评价；对目标域更新与直接外部评价分别报告。稀有结局以 Average Precision（AP）为主指标，并同时报告 ROC-AUC、Brier 分数、校准和预警负担。
